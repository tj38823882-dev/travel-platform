# 旅遊行程平台專案功能統整 (Travel Itinerary Platform - 功能清單)

本專案是一個具備社群互動與虛擬點數交易性質的旅遊行程服務平台，前後端分離架構 (Vue.js + Spring Boot)。

以下為目前系統的主要功能統整：

## 1. 帳號與權限系統 (User & Authentication)
- **會員登入/註冊**：包含基於 JWT (JSON Web Token) 的身分驗證，保障連線安全性 (loginView)。
- **個人資料管理**：會員專屬的個人中心頁面，可隨時查看個人資訊 (ProfileView)。
- **權限管控**：透過路由守衛 (Router Guard) 與後端 Security 進行前後端權限/角色區分（如：會員與管理員）。

## 2. 行程與購物車管理 (Tour & E-Commerce)
- **旅遊行程瀏覽**：展示所有旅遊行程商品，支援響應式設計展示 (ToTourList)。
- **購物車系統**：使用者可將行程加入購物車並進行管理 (CartView)。
- **結帳與訂單查詢**：支援商品結帳流程，並於後續供會員查詢歷史訂單與購買紀錄 (Checkouts / Profile View Orders)。

## 3. 虛擬點數與金流儲值 (Points & Payment System)
- **點數錢包機制**：系統以「點數」取代或輔助現金交易，導覽列 (Navbar) 具備即時點數餘額顯示與快捷儲值入口。
- **儲值方案與購買**：提供多種點數購買方案 (PointPackages) 供使用者選擇 (TopUpView)。
- **Line Pay 支付整合**：串接知名第三方金流 Line Pay，並具備付款確認機制與回調處理 (PaymentConfirm)。
- **點數交易紀錄**：提供儲值訂單與點數異動歷史明細，供用戶隨時對帳。

## 4. 社群互動與留言板 (Social & Community)
- **好友系統**：會員可以互相加為好友與進行好友名單管理 (friendView)。
- **即時文字聊天**：建立於好友系統之上的聊天室功能，具備對話框及訊息發送接收機制。
- **留言板與評論**：會員專屬的討論區、旅遊心得分享或行程評論機制 (MessageBoardView)。

## 5. 後台管理介面 (Admin System)
- **會員管理**：針對管理員帳號提供的專屬介面，可進行全站用戶名單的管理與狀態核對 (AdminUserList)。

## 6. UI / UX 現代化前端設計
- **高質感介面**：全站導入現代化排版、動態過場動畫及毛玻璃特效 (Glassmorphism)，並配合精選字體及漸層配色。
- **直覺的操作動線**：如導覽列整合了個人頭像、點數、購物車捷徑，並採用互動性強的組件優化體驗。
